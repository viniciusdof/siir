# App icon

`siir.svg` is the OpenMoji "articulated lorry" emoji (U+1F69B) by Ronja
Bäurlen, from <https://openmoji.org/library/emoji-1F69B/>, unmodified.
`siir.png` (Linux), `siir.icns` (macOS), and `siir.ico` (Windows) are rendered
from it by `just icons`.
