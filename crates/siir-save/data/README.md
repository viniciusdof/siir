# Catalog snapshots

`ets2.json` and `ats.json` are generated by `just catalog`. Do not edit them by
hand.

```sh
just catalog          # both games
just catalog ets2     # one game
```

The recipe builds `sk-zk/Extractor` in `target/`, extracts `/def` from the
installed game's `def.scs` and `dlc_*.scs`, and runs the `catalog` example in
`siir-save`. The extracted files stay in `target/game-data/` and are not
committed. Regenerate the snapshots after a game update.

Schema: `format`, `game`, `trucks`. Each truck has `brand`, `model`, `engines`,
`transmissions`, `cabins`, `chassis`, and `paint_jobs`.
